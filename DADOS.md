# Licença dos dados

Os arquivos de ruas (os das Releases e os que você gerar) contêm dados de **© OpenStreetMap contributors**, disponíveis sob a [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Veja também a [página de direitos autorais do OpenStreetMap](https://www.openstreetmap.org/copyright).

Em resumo (o texto da licença é o que vale):

- **Dê o crédito** "© OpenStreetMap contributors" onde o mapa aparecer e informe a licença.
- **Compartilhe igual:** se você usar publicamente uma base adaptada destes dados, ofereça essa base sob a ODbL.
- **Mantenha aberto:** não distribua os dados só com travas que impeçam o uso.

Se você tem dados próprios (preços, lojas, cadastros), mantenha-os **separados** destes arquivos, sem misturar nem cruzar as bases, e consulte as [orientações da OpenStreetMap Foundation](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Collective_Database_Guideline_Guideline). Isto não é aconselhamento jurídico.

A licença MPL 2.0 deste repositório vale para o **código**, não para os dados.
